# Dashboard de Ventas Retail

Dashboard interactivo desarrollado en Microsoft Excel para análisis de ventas de una tienda retail.

## Herramientas utilizadas
- Microsoft Excel
- Tablas dinámicas
- Slicers (segmentaciones de datos)
- Gráficos dinámicos

## Contenido
- **Hoja Data:** Dataset original con 1,000 transacciones de ventas
- **Hoja Análisis:** Tablas dinámicas con análisis por categoría, género, mes y edad
- **Hoja Dashboard:** Visualización interactiva con gráficos y KPIs

## KPIs incluidos
- Total de ventas
- Total de transacciones
- Promedio por venta
- Categoría más vendida

## Dataset
Datos obtenidos de Kaggle - Retail Sales Dataset
